Manage Tools

ADD shows a tool on the site. REMOVE hides it. EDIT changes the tool's name and description. DELETE removes it from the site in this browser: a tool you added here is removed completely, a built-in tool goes to "Deleted tools" below where you can restore it. DELETE does not delete files from VS Code. To make an EDIT or DELETE permanent for everyone, click Download tools.json below and replace data/tools.json in VS Code.

Add a new tool

Step 1: create the tool folder in VS Code first, at tools/<category>/<slug>/, with index.html, style.css and script.js. Step 2: fill in this form. Step 3: click Download tools.json and replace data/tools.json to make it permanent. Full steps: docs/adding-new-tools.md.

After downloading, replace data/tools.json in VS Code with the downloaded file.
