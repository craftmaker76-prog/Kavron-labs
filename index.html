How it works

  1. Pick a tool below.
  2. Use it in your browser - most tools never upload your files anywhere.
  3. Download the real result.

PDF tools use the pdf-lib library from a CDN, loaded only on PDF tool pages, so the homepage stays light. If you are offline, PDF tools will show a clear message instead of a fake result.

For the site owner

Open the Admin Panel to hide or show tools, add a new tool, view settings, and view the admin action log. To add a tool permanently, create its folder under tools/ in VS Code, then add it in Admin > Tools - see docs/adding-new-tools.md.
